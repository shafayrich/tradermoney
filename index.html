Documentation & Help

Getting Started

  1. Download the app for your platform.
  2. Launch TraderMoney. The free tier allows Signal‑Only mode on Alpaca paper.
  3. Paste your Alpaca API Key & Secret (get them from alpaca.markets). Enable Paper Trading.
  4. Enter your tickers (e.g., AAPL, TSLA:2, MSFT). Quantities after colon set per‑symbol size.
  5. Click Start Bot. Signals will appear in the Signals tab.

Broker Setup

  • Alpaca: API Key + Secret. Check “Paper Trading” for simulation. Live requires a funded account.
  • Interactive Brokers: TWS or IB Gateway must be running with API enabled. Default port: 7497 (paper) / 7496 (live).
  • Tradier: Access token from developer.tradier.com. Use Sandbox for testing.
  • Binance: API Key + Secret. Testnet available via checkbox.
  • Bybit: API Key + Secret. Uses unified account. Testnet supported.
  • OKX: API Key + Secret + Passphrase. Demo trading checkbox.

All credentials are encrypted locally with Fernet (safe‑write). No cloud storage.

Indicators & Confirmation Logic

The engine runs EMA(9,50) crossover and confirms with up to 9 additional filters. Each toggleable indicator adds confidence (0.05–0.08). Only crossed‑above signals with all active filters passing generate a BUY.

  • RSI: Long requires RSI ≥ 30; short requires RSI ≤ 70.
  • MACD: Long needs MACD > Signal line; short the opposite.
  • VWAP: Price > VWAP for long, < VWAP for short.
  • Bollinger Bands: Price above lower band (99%) for long; below upper for short.
  • ADX: Must be ≥ 20 to indicate trend strength.
  • Volume: Current volume ≥ 1.5× 20‑period average.
  • SuperTrend: Trend must be up (1) for long, down (-1) for short.
  • Stochastic: %K > %D and %K < 80 for long; %K < %D and %K > 20 for short.

Risk Management

  • ATR Stops: Dynamic stop‑loss = 2× ATR, take‑profit = 3× ATR. Adapts to volatility.
  • Bracket Orders: Native SL/TP on Alpaca; watchdog thread emulates them on other brokers.
  • Kill Switch: Instantly closes all positions and stops the bot.
  • SL/TP Watchdog: For non‑Alpaca brokers, a background loop monitors price every 2 seconds and exits at fixed 2%/4% thresholds if bracket isn't supported natively.

Backtesting

Press Backtest All (or the button in the Backtest tab) to run historical signal generation on all your tickers. Choose the lookback days. Results show timestamps, indicator values, and confidence scores. Use it to tune your indicator combination before going live.

Tips & Troubleshooting

  • No signals? Too many filters enabled. Try toggling SuperTrend or Stochastic off.
  • Free tier restrictions: Only 1 ticker, Alpaca paper, signal‑only, core indicators. Upgrade to Pro for full access.
  • Chart not loading? Ensure internet connection. The TradingView widget loads from CDN.
  • License not recognized? Verify your key at Gumroad. If valid, restart the app.

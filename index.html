Frequently Asked Questions

Is there a free trial of Pro? ▾
There is no free trial of Pro, but the free tier lets you test the full workflow with 1 ticker on Alpaca paper trading. All features (signals, monitors, charts, backtesting) work in free mode so you can evaluate before upgrading.
What brokers are supported? ▾
Alpaca, Interactive Brokers, Tradier, Binance, Bybit, and OKX. Free tier limits you to Alpaca paper trading. Pro unlocks all brokers with both paper and live trading modes.
Do I need coding experience? ▾
No. TraderMoney is a desktop app with a visual interface. Select your indicators, set your tickers, and start the bot. No Python or trading API knowledge required.
How does the AI confidence scoring work? ▾
Each active indicator contributes a weighted confidence score (0.05-0.08 per indicator). The base EMA crossover generates a signal, then every confirming indicator adds to confidence. News sentiment from NewsAPI is analyzed by AI (via OpenRouter) and can add up to ±20% confidence depending on sentiment polarity.
Can I run this on a VPS / headless server? ▾
Yes. The app runs as a Flask web server (port 5050). You can install it on any Linux/macOS VPS and access the UI from your browser. The pywebview native window is optional.
Is my API key safe? ▾
All credentials are stored in an encrypted local file using Fernet (symmetric encryption). They are never sent to any cloud server or third party. The app runs entirely on your machine.
What are the system requirements? ▾
macOS 13+ (Ventura) or Windows 10+. Apple Silicon Macs supported via Rosetta 2 (native build coming soon). 4GB RAM recommended. Internet connection required for market data and AI analysis.

Getting Started

Quick Start

  1. Download the app for your platform.
  2. Launch TraderMoney. The free tier allows Signal-Only mode on Alpaca paper.
  3. Paste your Alpaca API Key & Secret (get them from alpaca.markets). Enable Paper Trading.
  4. Enter your tickers (e.g., AAPL:10, TSLA:5). Quantities after colon set per-symbol size.
  5. Click Start Bot. Signals appear in the Monitor tab.

Broker Setup

  • Alpaca: API Key + Secret. Check "Paper Trading" for simulation. Live requires a funded account.
  • Interactive Brokers: TWS or IB Gateway must be running with API enabled. Default port: 7497 (paper) / 7496 (live).
  • Tradier: Access token from developer.tradier.com. Use Sandbox for testing.
  • Binance: API Key + Secret. Testnet available via checkbox.
  • Bybit: API Key + Secret. Uses unified account. Testnet supported.
  • OKX: API Key + Secret + Passphrase. Demo trading checkbox.

Indicators & Strategy

EMA(9,50) crossover is the core signal. Confirm with any combination of:

  • RSI: Long requires RSI ≥ 30; short requires RSI ≤ 70.
  • MACD: Long needs MACD > Signal; short the opposite.
  • VWAP: Price > VWAP for long, < VWAP for short.
  • Bollinger Bands: Price above lower band for long; below upper for short.
  • ADX: Must be ≥ 20 to indicate trend strength.
  • Volume: Current volume ≥ 1.5× 20-period average.
  • SuperTrend: Trend must be up for long, down for short.
  • Stochastic: %K > %D and %K < 80 for long; %K < %D and %K > 20 for short.

Risk Management

  • ATR Stops: Dynamic stop-loss = 2× ATR, take-profit = 3× ATR. Adapts to volatility.
  • Bracket Orders: Native SL/TP on Alpaca; watchdog thread emulates them on other brokers.
  • Kill Switch: Instantly closes all positions and stops the bot.
  • SL/TP Watchdog: Background loop monitors price every 2 seconds and exits at fixed thresholds if bracket isn't supported natively.

Frequently Asked Questions

Is there a free trial of Pro? ▾
There is no free trial of Pro, but the free tier lets you test the full workflow with 1 ticker on Alpaca paper. All features — signals, monitors, charts, backtesting — work in free mode so you can fully evaluate before upgrading.
What brokers are supported? ▾
Alpaca, Interactive Brokers, Tradier, Binance, Bybit, and OKX. Free tier limits you to Alpaca paper. Pro unlocks all brokers with both paper and live trading.
Do I need coding experience? ▾
No. TraderMoney is a desktop application with a visual interface. Select your indicators, set your tickers, and start the bot. No Python or API knowledge required.
How does the AI confidence scoring work? ▾
Each active indicator contributes a weighted confidence score. The base EMA crossover generates a signal, then every confirming indicator adds 0.05-0.08 to the confidence. News sentiment from NewsAPI is analyzed via OpenRouter AI and can adjust confidence by up to 20% depending on polarity.
Can I run this on a VPS? ▾
Yes. The app runs as a Flask web server on port 5050. Install on any Linux or macOS VPS and access the dashboard from your browser. The native pywebview window is optional.
Is my API key safe? ▾
All credentials are encrypted locally using Fernet symmetric encryption. They are never transmitted to any third party. The entire application runs on your machine.
What are the system requirements? ▾
macOS 13+ (Ventura) or Windows 10+. Apple Silicon supported via Rosetta 2. 4 GB RAM recommended. An internet connection is required for market data and AI analysis.
How do bracket orders work across brokers? ▾
All 6 brokers now support native stop-loss and take-profit orders placed alongside the entry market order. Alpaca uses native bracket orders. IBKR, Tradier, Binance, Bybit, and OKX place separate SL and TP orders automatically after the fill. A watchdog thread runs as a fallback safety net for all non-Alpaca brokers.

Getting Started

  1. Download the app for your platform.
  2. Launch TraderMoney. The free tier enables Signal-Only mode on Alpaca paper trading.
  3. Paste your Alpaca API Key & Secret from alpaca.markets. Enable Paper Trading.

Indicator Logic

EMA(9,50) crossover is the core signal. Confirm with any combination of:

  • RSI: Long requires RSI ≥ 30; short requires RSI ≤ 70.
  • MACD: Long needs MACD > Signal; short the opposite.
  • VWAP: Price > VWAP for long, < VWAP for short.
  • Bollinger Bands: Price above lower band for long; below upper for short.
  • ADX: Must be ≥ 20 to confirm trend strength.
  • Volume: Current volume ≥ 1.5× 20-period average.
  • SuperTrend: Up for long, down for short.
  • Stochastic: %K > %D and %K < 80 for long; %K < %D and %K > 20 for short.

Risk Management

  • ATR Stops: Dynamic stop-loss = 2× ATR, take-profit = 3× ATR. Adapts to volatility automatically.
  • Bracket Orders: Native SL/TP on all 6 brokers — stop-loss and take-profit placed at entry automatically.
  • Kill Switch: Instantly closes all positions and stops the bot.
  • SL/TP Watchdog: Background safety net monitors price every 2 seconds as a fallback.

Position Sizing

Two complementary ways to control trade size. Both can be used together.

1. Share/Contract Quantity

Set a fixed number of shares per trade in the Default Qty field. Per-ticker overrides: enter AAPL:10 in the tickers field to trade 10 shares of AAPL regardless of other tickers.

2. Max Spend Per Trade ($)

Set a dollar cap in the Connection sidebar under "Max Spend Per Trade (0 = unlimited)". The bot calculates shares = floor(max_spend / current_price) and never exceeds this amount. Example: max_spend = $200, AAPL at $150 → buys 1 share. AAPL at $50 → buys 4 shares. Set to 0 to disable (use fixed quantity only). Works with all brokers.

AI & Signals

TraderMoney uses a multi-factor signal engine combined with optional AI analysis.

Signal Generation

Each indicator votes BUY, SELL, or NEUTRAL. Votes are weighted and summed. If total confidence exceeds the threshold (default 60%), a signal fires.

AI Enhancement

When enabled, market data + indicator readings + news headlines are sent to an AI model (via OpenRouter) for final analysis. The AI can override, confirm, or refine the signal. Uses free models by default — no API key needed. Pro users can configure custom model endpoints.

Signal Types

  • BUY: Go long. Entry price, quantity, stop-loss, and take-profit calculated automatically.
  • SELL: Go short (if supported by broker) or exit long position.
  • EXIT: Close all open positions for this ticker.

Troubleshooting

Bot starts but no signals appear

Check that tickers are valid and the timeframe is set. Ensure at least one indicator is enabled. If using AI, check the AI tab for error messages. Try disabling AI to see if signals fire without it.

"Invalid API Key" error

Verify your broker API key and secret are correct. For Alpaca, ensure you're using the right URL (paper vs live). Keys are stored locally and never sent anywhere except your broker.

Charts not loading

TradingView widgets require internet. If blank, check your connection. If you see "TradingView" but no chart, try reloading from the Charts tab. TV login is not required for chart rendering.

Trades not executing

Ensure mode is set to "Auto Trade". Check broker account has sufficient buying power. Verify the broker URL is correct. Check the Status tab for error messages.

News not showing

News requires a free NewsAPI key. Create a .env file next to the app with NEWS_API_KEY=your_key. Get a key at newsapi.org/register. Free tier allows 100 requests/day.

App won't open / "damaged" warning on macOS

Go to System Settings → Privacy & Security and click "Open Anyway". Or run xattr -dr com.apple.quarantine /Applications/TraderMoney.app in terminal.

Can I run it 24/7?
